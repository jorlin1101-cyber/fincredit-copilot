# FinCredit Copilot 合成演示材料

本目录由 `scripts/generate_synthetic_documents.py` 生成，包含身份证、收入证明、银行流水各 10 份 PDF。全部文件均带有“合成数据｜仅供演示”水印，不对应任何真实个人、账户或机构。演示身份证号码均故意设置为无法通过居民身份证校验码验证的虚构号码，禁止用于任何真实身份识别场景。

重点演示组合：

- `CASE-01`：正常一致，用于完整授信辅助闭环。
- `CASE-05`：姓名不一致，用于跨材料一致性异常演示。
- `CASE-06`：收入不一致，用于收入证明与银行流水偏差演示。
- `CASE-02`：多页材料，用于页级证据定位演示。
- `CASE-03`：模糊材料，用于低置信度人工复核演示。
- `CASE-04`：关键字段缺失，用于补件门禁演示。

`manifest.json` 记录每份材料的类型、场景、质量、页数和合成标识，便于批量导入与回归测试。
